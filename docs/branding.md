# Creator Ops Brand Direction

## Product name

**Creator Ops**

The name communicates the product position directly: an operating system for creator operations rather than another generic note-taking tool.

## Logo direction

Use a simple geometric mark that can work as a GitHub avatar, browser favicon, and SaaS sidebar icon.

Recommended concepts:

1. **Loop mark** — six connected points or segments representing Inspiration, Topic, Content, Publication, Metrics, and Review.
2. **CO monogram** — a compact `C` wrapping an `O`, suggesting a continuous operating loop.
3. **Pipeline-to-loop** — a short linear path that curves back into itself, representing learning feeding the next creative cycle.

Avoid camera, microphone, play-button, or social-network-logo clichés. The system manages creator operations across media formats, not only video.

## Visual personality

- professional, calm, analytical;
- dark navigation with light workspace surfaces;
- one restrained violet accent for decisions and primary actions;
- data views should feel operational rather than promotional.

The current UI intentionally follows this direction while the final logo asset remains separate from the application code.
